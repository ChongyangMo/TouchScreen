# touchscreen

ESP32-S3 驱动淘晶驰串口屏 TJC3224T120_011R（主控 AIHMI C2，320×240 电阻触摸），做成电脑性能监视器。不需要 USART HMI，也不改屏里原有的工程。

屏上显示 CPU、内存、显卡占用率，内存和显存用量，GPU 温度，上传下载网速，以及最近 60 秒的曲线。点 CPU、内存、显卡或上传下载那一行，底部曲线切换成对应指标；点标题栏切换亮度。

## 接线

屏的线色和丝印对不上，**以丝印为准**：

| 屏丝印 | 线色 | 接到 |
|---|---|---|
| GND | 红 | 外部 5V 电源负极，同时接 ESP32 GND（必须共地） |
| RX | 黑 | ESP32 GPIO17 |
| TX | 黄 | ESP32 GPIO18 |
| 5V | 绿 | 外部 5V 电源正极 |

## 使用

1. 用 PlatformIO 编译并烧录 ESP32：`pio run -t upload`
2. 电脑端安装依赖：`pip install psutil pyserial`
3. 运行采集脚本：`py pc/pc_monitor.py`。脚本按乐鑫 USB VID 自动查找 ESP32，也可以指定串口：`py pc/pc_monitor.py COM3`

显卡数据通过 `nvidia-smi` 读取，没有 NVIDIA 显卡时显示 N/A。

## 实现要点

- ESP32 上电后用 `connect` 指令探测屏的波特率，再临时切到 921600。屏断电后会恢复成 9600，ESP32 收到屏的重启信号后自动重新联机。
- 屏执行指令的速度比串口慢，所以开启 `bkcmd=3`，让屏对每条指令回一个确认，最多允许 16 条未确认。不加这层流控，整列重画曲线时屏会报缓冲区溢出（`24`）。
- 屏里原工程的字库不全：1 号字库（24px）只有 A–Z、0–9、`/`、`+`；0 号字库（16px）只有 0–9、`%`、`.`。冒号和小数点由 ESP32 画小方块补上。
- 中文标签用 `pc/gen_cn_font.py` 从微软雅黑渲染成矩形点阵，生成 `src/cn_font.h`，ESP32 用 `fill` 指令逐块画出来。要改中文文字时，修改脚本里的 `CHARS` 后重新生成，再重新烧录。
- 曲线是逐列覆盖的面积图：每列直接画成最终颜色，不先清空，所以滚动时不闪；内容没变的列跳过不画。
